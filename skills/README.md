# skills/

Instalirani skill paketi za ovaj projekat — proširena znanja koja agent učitava
po potrebi (dizajn sistem, UI/UX, teardown sajtova, brend).

Struktura: jedan folder po skill-u, svaki sa svojim `SKILL.md`.

Kandidati koji se koriste na sličnim projektima:
`ui-ux-pro-max`, `design`, `design-system`, `brand`, `banner-design`,
`ui-styling`, `slides`, plus `site-teardown`.

Ako treba isti paket kao na Random/PATO projektu, može da se iskopira odande.
