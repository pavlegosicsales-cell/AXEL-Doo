# brand_assets/

Izvorni brend materijal — ono što je klijent dao ili što je odobreno kao
zvanično. Ovo se ne izmišlja i ne prepravlja bez dogovora.

Šta ide ovde:

- Logo (SVG/PNG, transparentna verzija, varijante za svetlu/tamnu podlogu)
- `Brand_guidelines.md` — paleta, tipografija, ton komunikacije, pravila
- Fotografije ljudi / radova / objekta koje dolaze od klijenta
- Fontovi, ako su licencirani i dostavljeni

Razlika u odnosu na `assets/`: ovde je **izvor**, tamo je ono što ide na sajt.
