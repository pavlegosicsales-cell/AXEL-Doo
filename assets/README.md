# assets/

Radni fajlovi koji idu u proizvod — obrađene slike, ikone, video, inspiracija.

Šta ide ovde:

- Optimizovane slike za sajt (skalirane, webp gde ima smisla)
- Ikone, grafike, pozadine
- `inspo*/` — reference sa drugih sajtova, teardown izvori

Napomena o performansama: skaliraj izvorne slike pre nego što odu u produkciju.
Velike originalne slike + fiksne pozadine seckaju na telefonu.
