# workflows/

Markdown SOPs — one file per workflow. Each defines:

- **Objective** — what this workflow accomplishes
- **Inputs** — required inputs and where they come from
- **Tools** — which scripts in `tools/` to run, in what order
- **Outputs** — expected deliverables and where they go
- **Edge cases** — how to handle failures and quirks

Keep these current. When you learn something (rate limits, better methods,
constraints), update the relevant workflow — but ask before creating or
overwriting one.
